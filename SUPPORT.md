# Support

Start with the [quick start](docs/quickstart.md) and
[troubleshooting guide](docs/troubleshooting.md).

For a reproducible bug, use the
[bug report form](https://github.com/MusicMaster4/Duckweed/issues/new?template=bug_report.yml).
For a proposed improvement, use the
[feature request form](https://github.com/MusicMaster4/Duckweed/issues/new?template=feature_request.yml).

Useful reports include the Duckweed version, operating system, shell, agent
CLI, reproduction steps, and a short redacted output sample. Do not include
passwords, API keys, access tokens, private repository contents, or full agent
transcripts.

Duckweed is a source-available local application. It does not upload project
files or agent transcripts, and it does not create a Duckweed account. Provider
CLIs may still contact their own services.

Please keep reports specific and respectful. We would rather have one clear
reproduction than a pile of promotional comments. See [CONTRIBUTING.md](CONTRIBUTING.md)
for code, documentation, and release contributions.
